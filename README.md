# Speech to Text Demo

A modern Speech-to-Text application built with React, Vite, and the Web Speech API.

## Prerequisites

- Node.js installed (v16 or higher recommended).

## Setup & Run

1.  **Install Dependencies**:
    Open your terminal in this directory and run:
    ```bash
    npm install
    ```

2.  **Start the Development Server**:
    ```bash
    npm run dev
    ```

3.  **Open in Browser**:
    Click the link shown in the terminal (usually `http://localhost:5173`).

## Features

- **Real-time Transcription**: Converts speech to text instantly.
- **Visual Feedback**: Pulse animation when recording.
- **Copy & Clear**: Easy controls to manage your notes.
- **Privacy**: Uses the browser's native Web Speech API.
